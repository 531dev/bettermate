# Logos

- `bettermate-wordmark.svg`: the wordmark in ink `#111111`, for Light grounds (`surface-0`, `surface-1`, `surface-2`). "Better" at weight 600 and "Mate" at 400 in Space Grotesk, set as outlines.
- `bettermate-wordmark-inverse.svg`: the same outlines in `#f2f2f2`, for Dark and Display black.

The wordmark keeps these Space Grotesk outlines; the interface itself is set in Funnel Display. Use the files, never live text. Height 20 px in the web's top bar and sidebar. Keep clear space of half the wordmark's height on every side. Upstream GaggiMate marks are not used; the credit "Based on GaggiMate" stays in the sidebar and in Settings.
